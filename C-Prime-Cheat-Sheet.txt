C-Prime Syntax Cheat Sheet
=========================

What is C-Prime?
----------------
C-Prime is a small systems-style programming language built as a Rust-style compiler project.
It supports functions, variables, structs, methods, generics, loops, conditionals, pointers,
and pattern matching.

The compiler front end handles:
- lexing
- parsing
- semantic/type checking
- optional LLVM-based code generation when enabled

Project usage
-------------
From the project root, run:

    cargo run --quiet -- --lex file.cp
    cargo run --quiet -- --parse file.cp
    cargo run --quiet -- --check file.cp

The most useful command is:

    cargo run --quiet -- --check your_program.cp

It verifies that the code is accepted by the compiler.

1. Imports
----------

    import std.io;

Dot-separated module paths are allowed.

2. Functions
------------

    fn main() -> i32 {
        return 0;
    }

    fn add(a: i32, b: i32) -> i32 {
        let total: i32 = a + b;
        return total;
    }

Function syntax:
- fn name(params) -> return_type {
- return statements can be used with or without a value

3. Variables
-------------

    let x: i32 = 10;
    let mut total: i32 = 0;

    x = x + 1;
    total = total + x;

Notes:
- let declares a variable
- mut makes it mutable
- type annotations are usually explicit in examples

4. Conditionals
---------------

    if x > 0 {
        println(x);
    } else {
        println(0);
    }

    if a == b {
        return 1;
    }

5. Loops
---------

While loop:

    let mut i: i32 = 0;
    while i < 10 {
        i = i + 1;
    }

For loop:

    for ch in "C-Prime" {
        println(ch);
    }

6. Structs
----------

    struct Point {
        x: f64,
        y: f64
    }

Struct values are instantiated like this:

    let p: Point = Point { x: 1.5, y: 2.5 };

7. Impl blocks and methods
--------------------------

    impl Point {
        fn new(x: f64, y: f64) -> Point {
            return Point { x: x, y: y };
        }

        fn add(self, other: Point) -> Point {
            return Point { x: self.x + other.x, y: self.y + other.y };
        }
    }

Usage:

    let a: Point = Point::new(1.0, 2.0);
    let b: Point = Point::new(3.0, 4.0);
    let c: Point = a.add(b);

8. Generics
-----------

    fn swap[T](a: *mut T, b: *mut T) {
        let tmp: T = *a;
        *a = *b;
        *b = tmp;
        return;
    }

The generic type parameter appears in square brackets after the function name.

9. Pointers
-----------

    let mut value: i32 = 42;
    let ptr: *mut i32 = &mut value;
    *ptr = 99;

Available pointer styles include:
- *const T
- *mut T

10. Match expressions
---------------------

    match value {
        0 => println("zero"),
        1 => println("one"),
        _ => println("other"),
    }

Pattern examples:
- literal values such as 0, 1, true
- wildcard _ as default branch

11. Printing
------------

    println("hello");
    println(42);
    println(3.14);

12. Primitive types
-------------------

- bool
- char
- i8, i16, i32, i64, i128
- u8, u16, u32, u64, u128
- f32, f64
- isize, usize
- void

13. Example program
-------------------

    import std.io;

    struct Vector2 {
        x: f64,
        y: f64
    }

    impl Vector2 {
        fn new(x: f64, y: f64) -> Vector2 {
            return Vector2 { x: x, y: y };
        }

        fn length(self) -> f64 {
            return self.x * self.x + self.y * self.y;
        }
    }

    fn main() -> i32 {
        let v: Vector2 = Vector2::new(2.0, 3.0);
        println(v.length());
        return 0;
    }

14. Quick tips
--------------
- Use semicolons to terminate statements.
- Control flow uses braces blocks.
- Return types must match what the function returns.
- Generic functions are written like fn name[T](...)
- Use match arms as pattern => action

15. Calling C (extern), null, casts
-----------------------------------

    extern fn malloc(size: usize) -> *mut void;
    extern fn strlen(s: *const char) -> usize;

    let p: *mut i32 = malloc(64) as *mut i32;
    if p == null {
        // ...
    }
    free(p);

    let n: i32 = 3.9 as i32;          // 3
    let c: char = (48 + 1) as char;   // '1'
    let s: *const char = "hi";        // literal coerces to *const char

- null is a literal for any pointer type
- pointer == pointer and pointer == null comparisons work
- malloc/free/strlen/modf/... are pre-bound in examples/std/ctypes.cp

16. Including files
-------------------

    include "std/raylib.cp";
    include "std/ctypes.cp";

- Paths are relative to the including file; recursion is allowed
  (cycles are rejected).

17. Building executables (codegen feature)
-----------------------------------------

    cargo run --quiet --features codegen -- --check file.cp
    cargo run --quiet --features codegen -- --emit-llvm out.ll file.cp
    cargo run --quiet --features codegen -- --link -o out.exe file.cp

Extra libraries / search paths:

    --link-lib raylibdll --lib-path ..\..\third_party\raylib

18. Language gotchas
--------------------
- if is a statement: no let x = if ...  (and no implicit return)
- A value-returning function must end with explicit return expr;
- Every statement ends with a trailing semicolon
- & / | bind looser than == / !=: write (mask & bit) != 0
- const NAME: ty = value; needs the type annotation
- No arrays: use malloc + buf[i] pointer indexing
- Str is not a valid named type; use *const char

19. Best validation command
---------------------------

    cargo run --quiet --features codegen -- --check examples/feature_demo.cp

If it prints a success message like:

    check succeeded: ... no semantic errors

then the source is accepted by the language front end.

This guide reflects the language features currently implemented in this project.
