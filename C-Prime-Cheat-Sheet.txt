C-Prime Syntax Cheat Sheet
=========================

What is C-Prime?
----------------
C-Prime is a small systems programming language with a Rust-inspired syntax.
The compiler lexes, parses, typechecks, and (with the codegen feature)
generates LLVM IR and native executables via clang.

Project usage
-------------
    cargo run --quiet -- --lex file.cp          # dump tokens
    cargo run --quiet -- --parse file.cp        # parse + AST summary
    cargo run --quiet -- --check file.cp        # typecheck
    cargo run --quiet --features codegen -- --check file.cp

With LLVM codegen enabled:

    cargo run --quiet --features codegen -- --emit-llvm out.ll file.cp
    cargo run --quiet --features codegen -- --link -o out.exe file.cp
    cargo run --quiet --features codegen -- --link --link-lib NAME --lib-path DIR -o out.exe file.cp

Test suites:

    cargo test                                       # front-end tests
    cargo test --features codegen                    # full suite incl. exe tests

1. Files and includes
---------------------
    include "std/vec.cp";

- Paths are relative to the including file.
- Duplicates are detected and skipped; recursion is rejected.

2. Functions
------------
    fn add(a: i32, b: i32) -> i32 {
        return a + b;
    }

    fn main() -> i32 {
        return 0;
    }

- Every statement ends with `;`.
- A value-returning function must end with `return expr;`.
- No implicit return; `if` is a statement, not an expression.

3. Variables
------------
    let x: i32 = 10;
    let mut y: i32 = 0;
    y = y + x;

- `let` declares a variable; `mut` makes it mutable.
- Type annotations are required on `let` without initializer.

4. Conditionals
---------------
    if x > 0 {
        println(x);
    } else if x == 0 {
        println(0);
    } else {
        println(-x);
    }

5. Loops
--------
    // while
    let mut i: i32 = 0;
    while i < 10 {
        i = i + 1;
    }

    // for over Vec[T]
    let mut v: Vec[i32] = Vec::new();
    v.push(1);
    for e in v { println(e); }

    // for over String
    for ch in "hello" { println(ch); }

- `break` and `continue` are supported in both loops.

6. Switch
---------
    switch value {
        case 1: printf("one\n"); break;
        case 2: printf("two\n"); break;
        default: printf("other\n"); break;
    }

7. Match
--------
    let x: i32 = match 2 {
        1 => 10,
        2 => 20,
        _ => 0,
    };

- Patterns: integer/char/bool literals, `_` wildcard, `name` binding.
- Match can be used as a value expression or as a statement.

8. Structs
----------
    struct Point {
        x: f64,
        y: f64
    }

    impl Point {
        fn new(x: f64, y: f64) -> Point {
            return Point { x: x, y: y };
        }
        fn add(self, other: Point) -> Point {
            return Point { x: self.x + other.x, y: self.y + other.y };
        }
    }

    let p: Point = Point::new(1.0, 2.0);

- `self` by value, `&self` by const ref, `&mut self` by mutable ref.
- Static methods have no `self` parameter.
- Struct literals: `Point { x: 1.0, y: 2.0 }` (fields inferred from type).

9. Generics
-----------
    fn swap[T](a: T, b: T) -> T { return b; }

    struct Box[T] { value: T }
    impl Box[T] {
        fn new(v: T) -> Box[T] { return Box[T] { value: v }; }
        fn get(self) -> T { return self.value; }
    }

- Multiple params: `struct Pair[A, B] { first: A, second: B }`
- Generic functions: `fn name[T](...)`
- Generic static calls: `Box::new(v)` (args inferred from context).

10. Enums
---------
    enum Color { Red, Green, Blue }
    enum class Grade : i32 { C = 2, B = 3, A = 4 }

- Enum variants evaluate to integer values (index or explicit value).
- `Color::Green` is `i32` value 1.

11. Type aliases and constants
------------------------------
    using Number = i32;
    const ANSWER: Number = 42;

12. Pointers
------------
    let mut val: i32 = 42;
    let ptr: *mut i32 = &mut val;
    *ptr = 99;
    let rp: *const i32 = &val;
    let np: *mut i32 = null;

- `*mut T` and `*const T` for mutable/const pointers.
- `&` takes address, `*` dereferences.
- `null` is a pointer literal; pointer == null works.

13. Casting
-----------
    let n: i32 = 3.9 as i32;          // 3
    let c: char = (48 + 1) as char;   // '1'
    let s: *const char = "hello";

- `as` casts between numeric types, char <-> int, pointer <-> pointer.
- Parentheses are needed for chained: `(*ptr) as i64`.

14. Calling C (extern)
-----------------------
    extern fn malloc(size: usize) -> *mut void;
    extern fn free(p: *mut void);
    extern fn strlen(s: *const char) -> usize;

    let p: *mut i32 = malloc(64) as *mut i32;
    free(p as *mut void);

- Variadic: `extern fn printf(fmt: *const char, ...) -> i32;`
- Bindings live in `examples/std/ctypes.cp`.

15. Printing
------------
    println("hello");         // prints string + newline
    println(42);              // prints integer
    println(3.14);            // prints float
    println(true);            // prints 1

    // Format-checked printing with {}
    println("sum is {} plus {} = {}", a, b, sum);

- `{}` placeholders must match extra argument count (typechecked).
- Each `{}` is replaced by the corresponding printf format (%d, %lld, %f, %s, %p).

16. Primitive types
-------------------
    bool, char, void
    i8, i16, i32, i64, i128
    u8, u16, u32, u64, u128
    f32, f64
    isize, usize

17. Operators
-------------
    Arithmetic:  +  -  *  /  %
    Comparison:  ==  !=  <  >  <=  >=
    Logical:     &&  ||  !
    Bitwise:     &  |  ^  ~  <<  >>
    Assignment:  =  +=  -=  *=  /=  %=
    Address:     & (unary)  * (deref)

18. SizeOf
----------
    let s: usize = sizeOf[i32]() as usize;

- Syntax: `sizeOf[Type]()`
- Returns `usize`.

20. For-loop iteration
----------------------
- Over `Vec[T]`: element type is `T`
- Over `String`: element type is `char`
- Over `*const char` / string literals: element type is `char`

21. Language gotchas
--------------------
- `if` is a statement, not an expression: no `let x = if ...`
- No implicit return: a function returning a value needs `return expr;`
- Every statement ends with `;`
- `&` and `|` bind looser than `==` / `!=`: write `(a & b) != 0`
- Pointer arithmetic (ptr + 1) is not supported; use `buf[i]`
- Array literals `[1, 2, 3]` are parsed/typechecked but codegen is incomplete

This guide reflects the language features currently implemented in this project.
